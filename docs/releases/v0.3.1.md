업데이트 v1.2.0 을 설치한 본체에서도 게임 첫 화면의 타이틀 띠가 한글로 나옵니다. 게임 안 번역과 폰트는 v0.1 부터 같습니다.

**원본 일본판(`000400000016CE00`)에 적용하는 전체 패치입니다.** 두 파일 중 하나만 쓰면 됩니다.

## 변경 사항

- 패처로 **업데이트 CIA 도 패치할 수 있습니다.** 업데이트 v1.2.0 을 설치해 쓰고 있다면 본편과 업데이트를 함께 `패치하기.bat` 에 끌어다 놓으세요. v0.3 까지는 이 경우 첫 화면의 타이틀 띠가 일본어로 남았습니다.
- LayeredFS 로는 첫 화면의 타이틀 띠가 바뀌지 않습니다. 업데이트를 설치한 본체에서 문제가 생길 수 있어 그 파일을 뺐습니다. 블라스트 볼 화면의 띠는 그대로 한글입니다.
- 내려받는 크기가 줄었습니다. 패처 13.6MB, LayeredFS 3.7MB.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `BCAJ_KPatch_v0.3.1_CIA.zip` | 본인이 가진 일본판 `.cia` 또는 `.3ds` | 한글판 CIA·3DS 를 만드는 패처. 본편과 업데이트를 모두 패치할 수 있고, HOME 메뉴 배너·게임 이름까지 한글이 됩니다. |
| `BCAJ_KPatch_v0.3.1_LayeredFS.zip` | 원본 일본판 | SD 카드 루트에 푸는 LayeredFS 패치. 게임 안 텍스트와 블라스트 볼 화면의 타이틀 띠, `locale.txt` 와 사용자 설명서. |

게임 안 텍스트는 두 파일이 같습니다. 첫 화면 타이틀 띠까지 한글로 보려면 패처를 쓰세요.

## 적용 방법

1. 패처: ZIP 을 폴더째 풀고 일본판 `.cia` 를 `패치하기.bat` 에 끌어다 놓습니다. **업데이트 v1.2.0 을 설치해 쓰고 있다면 업데이트 CIA 도 함께 놓으세요.** 만들어진 CIA 를 FBI 등으로 설치합니다. 암호화된 원본이면 `boot9.bin` 과 `seeddb.bin` 이 필요합니다(이 게임은 seed 암호화를 씁니다).
2. LayeredFS: ZIP 안의 `luma` 폴더를 SD 카드 루트에 풉니다. Luma3DS 설정에서 **Enable game patching** 을 켭니다. Azahar 에서는 게임을 오른쪽 클릭해 **Open Mods Location** 을 누르고 그 폴더에 `romfs` 를 복사합니다.
3. **어느 방법이든 `sd:/luma/titles/000400000016CE00/locale.txt`(내용 `JPN JP`)는 필요합니다.** 일본판이 아닌 본체에서는 없으면 게임 시작 직후 크래시하며, Luma3DS 기능이라 CIA 에 담을 수 없습니다. 두 ZIP 모두에 들어 있습니다.
4. 예전에 다른 한글 패치를 썼다면 `sd:/luma/titles/000400000016CE00/` 폴더를 지우고 새로 풉니다. `init.jp` 와 `init.dict` 는 짝이 맞아야 합니다.

자세한 방법은 동봉한 `README_한국어.txt` 를 참고하세요.
