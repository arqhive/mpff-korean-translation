설치 방법을 두 가지로 늘린 버전입니다. 게임 안 번역과 폰트는 v0.1과 같고(`init.jp`, `init.dict`는 바이트 단위로 동일합니다), 가진 일본판 CIA·3DS 파일을 한글판으로 만들어 주는 패처가 새로 들어갔습니다.

**원본 일본판(`000400000016CE00`)에 적용하는 전체 패치입니다.** 두 파일 중 하나만 쓰면 됩니다.

## 변경 사항

- 드래그 앤 드롭 패처를 추가했습니다. 일본판 `.cia` 또는 `.3ds` 파일을 `패치하기.bat`에 끌어다 놓으면 `<원래 이름>_KO.cia`가 생깁니다. 파이썬과 도구가 함께 들어 있어 따로 설치할 것이 없습니다.
- 패처로 만든 CIA는 HOME 메뉴 배너와 게임 이름까지 한글로 나옵니다. LayeredFS로는 바뀌지 않는 부분입니다.
- 배포 파일 이름을 `MPFF_KO_v0.2_LayeredFS.zip`, `MPFF_KO_v0.2_Patcher.zip`으로 정리했습니다.
- 한글판 CIA 빌드에서 `ctrtool` 의존을 없애고 pyctr로 복호화하도록 바꿨습니다. `.3ds` 출력도 지원합니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `MPFF_KO_v0.2_LayeredFS.zip` | 원본 일본판 | SD 카드 루트에 푸는 LayeredFS 패치. `init.jp`, `init.dict`, `locale.txt`와 사용자 설명서. |
| `MPFF_KO_v0.2_Patcher.zip` | 본인이 가진 일본판 `.cia` 또는 `.3ds` | 한글판 CIA·3DS를 만드는 패처. HOME 메뉴 배너·게임 이름까지 한글이 됩니다. |

게임 안 한글은 두 파일이 같습니다. 설치된 게임을 그대로 두고 간단히 쓰려면 LayeredFS, HOME 메뉴까지 한글로 보고 싶으면 패처를 쓰세요.

## 적용 방법

1. LayeredFS: ZIP 안의 `luma` 폴더를 SD 카드 루트에 풉니다. Luma3DS 설정에서 **Enable game patching**을 켜고 게임을 실행합니다. Azahar에서는 게임을 오른쪽 클릭해 **Open Mods Location**을 누르고 그 폴더에 `romfs`를 복사합니다.
2. 패처: ZIP을 폴더째 풀고 일본판 `.cia` 또는 `.3ds`를 `패치하기.bat`에 끌어다 놓습니다. 만들어진 CIA를 FBI 등으로 설치합니다. 암호화된 원본이면 `boot9.bin`과 `seeddb.bin`이 필요합니다(이 게임은 seed 암호화를 씁니다).
3. **어느 방법이든 `sd:/luma/titles/000400000016CE00/locale.txt`(내용 `JPN JP`)는 필요합니다.** 일본판이 아닌 본체에서는 없으면 게임 시작 직후 크래시하며, Luma3DS 기능이라 CIA에 담을 수 없습니다. 두 ZIP 모두에 들어 있습니다.
4. 예전에 다른 한글 패치를 썼다면 `sd:/luma/titles/000400000016CE00/` 폴더를 지우고 새로 풉니다. `init.jp`와 `init.dict`는 짝이 맞아야 합니다.
5. 필요하면 SD에 넣은 두 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
