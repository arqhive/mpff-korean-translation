게임 안 그래픽에 남아 있던 일본어를 없앤 버전입니다. 게임 안 번역과 폰트는 v0.1 부터 같고(`init.jp`, `init.dict` 는 바이트 단위로 동일합니다), 타이틀 띠 2종이 한글로 바뀌었습니다.

**원본 일본판(`000400000016CE00`)에 적용하는 전체 패치입니다.** 두 파일 중 하나만 쓰면 됩니다.

## 변경 사항

- 게임 안 타이틀 띠를 한글로 바꿨습니다. 「メトロイドプライム フェデレーションフォース」와 「メトロイドプライム ブラストボール」 두 종이며, 같은 그림이 두 pak 에 들어 있어 파일로는 4장을 교체합니다.
- HOME 메뉴 배너 띠도 같은 그림으로 교체해 게임 안 타이틀과 글자체를 맞췄습니다.
- romfs 텍스처 6,142장을 전부 확인했습니다. 일본어가 박힌 그래픽은 위 2종뿐입니다. 시리즈 로고와 버튼 글리프는 원문 그대로 두었습니다.
- LayeredFS 배포 크기가 345KB 에서 9MB 로 늘었습니다. 띠 4장(16KB)을 바꾸려면 그 그림이 든 pak 두 개(19MB)를 통째로 넣어야 하기 때문입니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `MPFF_KO_v0.3_LayeredFS.zip` | 원본 일본판 | SD 카드 루트에 푸는 LayeredFS 패치. 게임 안 텍스트와 타이틀 띠, `locale.txt` 와 사용자 설명서. |
| `MPFF_KO_v0.3_Patcher.zip` | 본인이 가진 일본판 `.cia` 또는 `.3ds` | 한글판 CIA·3DS 를 만드는 패처. HOME 메뉴 배너·게임 이름까지 한글이 됩니다. |

게임 안 한글은 두 파일이 같습니다. 설치된 게임을 그대로 두고 간단히 쓰려면 LayeredFS, HOME 메뉴까지 한글로 보고 싶으면 패처를 쓰세요.

## 적용 방법

1. LayeredFS: ZIP 안의 `luma` 폴더를 SD 카드 루트에 풉니다. Luma3DS 설정에서 **Enable game patching** 을 켜고 게임을 실행합니다. Azahar 에서는 게임을 오른쪽 클릭해 **Open Mods Location** 을 누르고 그 폴더에 `romfs` 를 복사합니다.
2. 패처: ZIP 을 폴더째 풀고 일본판 `.cia` 또는 `.3ds` 를 `패치하기.bat` 에 끌어다 놓습니다. 만들어진 CIA 를 FBI 등으로 설치합니다. 암호화된 원본이면 `boot9.bin` 과 `seeddb.bin` 이 필요합니다(이 게임은 seed 암호화를 씁니다).
3. **어느 방법이든 `sd:/luma/titles/000400000016CE00/locale.txt`(내용 `JPN JP`)는 필요합니다.** 일본판이 아닌 본체에서는 없으면 게임 시작 직후 크래시하며, Luma3DS 기능이라 CIA 에 담을 수 없습니다. 두 ZIP 모두에 들어 있습니다.
4. 예전에 다른 한글 패치를 썼다면 `sd:/luma/titles/000400000016CE00/` 폴더를 지우고 새로 풉니다. `init.jp` 와 `init.dict` 는 짝이 맞아야 합니다.
5. 필요하면 SD 에 넣은 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt` 를 참고하세요.
