메트로이드 프라임 페더레이션 포스 한글 패치 v0.1
================================================

닌텐도 3DS 『메트로이드 프라임 페더레이션 포스』 일본판 한글 패치입니다.
게임 내 문자열 2,119개를 전부 번역했습니다.

대상: 일본판 (CTR-P-BCAJ, 타이틀 ID 000400000016CE00)
      업데이트 v1.2.0 이 설치돼 있어도 괜찮습니다.

※ 에뮬레이터에서 동작을 확인했고 실기 검증은 아직입니다(v0.1).
   문제가 있으면 알려 주세요.


설치 방법
---------

1. 이 압축 파일을 SD 카드 루트에 풉니다. 이런 모양이 됩니다.

   sd:/luma/titles/000400000016CE00/romfs/init.jp
   sd:/luma/titles/000400000016CE00/romfs/init.dict

2. Luma3DS 설정에서 "Enable game patching" 을 켭니다.

   본체 전원을 켤 때 SELECT 를 누른 채로 두면 Luma 설정 화면이 나옵니다.
   목록에서 Enable game patching 에 X 표시를 하고 START 로 저장합니다.

3. 게임을 실행합니다.


한글이 안 나올 때
-----------------

- Luma3DS 의 game patching 이 꺼져 있으면 아무 일도 일어나지 않습니다.
- 폴더 이름의 타이틀 ID 가 정확한지 보세요. 000400000016CE00 입니다.
  북미판(000400000016E300)에는 적용되지 않습니다.
- romfs 폴더 안에 init.jp 와 init.dict 가 **둘 다** 있어야 합니다.
  init.dict 를 빼면 게임 내 텍스트가 전부 빈칸으로 나옵니다.


HOME 메뉴 제목과 배너
---------------------

이 방식으로는 HOME 메뉴에 나오는 제목("フェデレーションフォース")과 배너를
바꿀 수 없습니다. 3DS 가 그 정보를 설치된 타이틀의 메타데이터에서 읽기
때문입니다. 게임 안 텍스트는 모두 한글로 나옵니다.

거기까지 한글로 하려면 본인이 가진 일본판 CIA 로 직접 한글판 CIA 를 만들어야
합니다. 저장소의 scripts/build_cia.py 와 docs/BUILD.md 를 보세요.


들어 있는 것
------------

  luma/titles/000400000016CE00/romfs/init.jp     게임 내 전체 텍스트 + 한글 폰트
  luma/titles/000400000016CE00/romfs/init.dict   위 파일의 청크 표


번역 기준
---------

대사와 문장은 북미판 원문을 옮겼습니다. 개발사(Next Level Games, 캐나다)가
쓴 원문이기 때문입니다. 용어와 고유명사는 일본판 표기를 따랐습니다.
시리즈 공식 한국어 표기가 있는 것은 그쪽을 우선했습니다.

  예) Space Pirates  → 우주 해적
      Federation     → 페더레이션
      lock-on        → 록온
      turret         → 터릿

외래어는 국립국어원 외래어 표기법을 따랐습니다(대미지, 커패시티, 타깃 등).
